# HD2 Mod Manager - 标签系统、Mod 库与配置文件页面设计（中文）

## 目标
- 架构遵循 程序-窗口-页面-卡片；Home 在面包屑显示为 `HD2ModManager`。
- Mod 库不做手动排序；按标签（被替换的游戏对象）进行分类整理。
- 配置文件仅允许启用一个；卡片可跳转到 Mod 详情；右键提供常用操作。
- 统一卡片系统与变体：加长（默认）、紧凑、大图（无图时自动回退）。

## 标签系统
- 标签层级：
  - 顶层：`护甲`、`武器`、`支援`、`其他`。
  - 护甲子类：`轻甲`、`中甲`、`重甲`。
  - 武器子类：`主要武器`（突击步枪/精确射手步枪/冲锋枪/霰弹枪/能量/爆炸/特殊）、`次要武器`（手枪/近战/特殊）、`投掷武器`（标准/特殊）。
  - 支援子类：`支援武器`、`支援背包`、`支援载具`、`支援哨兵`、`支援阵地`、`支援布雷器`。
  - 精确标签：编号（如 `FS-55`、`I-44`、`AR-23`、`MG-43`），可解析为名称、被动、属性。
- 派生标签：
  - 护甲编号 → 派生 `护甲` 与对应重量类别（轻/中/重）。
  - 武器/支援编号 → 派生 `武器`/`支援` 类别与子类。
  - 仅打 `护甲` 标签的 Mod 视为替换全部护甲；仅打 `轻甲/中甲/重甲` 也视为替换该类全部护甲。
- 数据来源：
  - `Resources/ArmorList.csv`（Category, Code, EnglishName, ChineseName, Passive, Source, Armor, Speed, Stamina）
  - `Resources/ArmorPassives.csv`（PassiveEnglish, PassiveChinese, DescriptionEnglish, DescriptionChinese）
  - `Resources/WeaponsList.csv`（Group, Subcategory, Code, EnglishName, ChineseName）
  - `Resources/SupportList.csv`（Category, Code, EnglishName, ChineseName）

## Mod 库界面
- 分段：
  - 护甲大段 → 子段：多种类型、轻甲、中甲、重甲。
  - 武器大段 → 按分组与子类细分子段。
  - 支援大段 → 按类别细分子段。
  - 其他大段 → 不在系统标签表中的标签归此。
- 卡片：
  - ModCard（基于跳转卡）：默认紧凑；顶部开关可切换到大图。
  - 标签悬停提示（精确护甲标签）：显示名称（中英）、被动（中英）、来源、护甲/速度/耐力。
- 控件：
  - 顶部：变体切换（紧凑/大图）、搜索卡（标签/名称筛选）。
  - ModCard右键：移除（确认）、添加到当前启用的配置文件（若无启用则禁用；如有选项则弹出选择）。
- 持久化：
  - Mod 库保存为 JSON：名称、备注、图片、标签、选项结构、统计、最后修改日期列表。

## Mod 详情页面
- 内容：
  - 超大图（可点击替换）、名称与备注可编辑、标签列表（可编辑）、统计信息。
  - 若存在选项/子选项：在下方展示并允许选择；按标签解决冲突。

## 配置文件页面
- 显示已激活 Mod 的卡片列表（卡片可跳转详情）。右键：从配置文件移除（不从库中移除）。
- 仅允许启用一个配置文件；首次创建/导入的配置文件自动启用。

## 选项型 Mod 的拆分导入
- 导入时检测含 patch 文件的文件夹：
  - 若包含选项，且选项目录包含 patch，则拆分为独立 Mod：
    - 名称格式：`主名称-选项` 或 `主名称-选项组-子选项`。
  - 每个拆分项继承其精确标签（例如仅标记 `护甲` 则视为替换全部护甲），并在库 JSON 中作为独立条目。
  - 不含 patch 文件的目录不生成 Mod。

## 标签设置工作流
- 导入新 Mod 时打开标签编辑窗口：
  - 依据名称提取建议标签（识别如 `FS-55`、`AR-23` 等编号）。
  - 下方展示完整标签库，支持筛选输入框快速查找。
  - 点击上方建议标签可移除到下方；点击下方库标签可添加到上方。
  - 支持新增自定义标签（筛选框旁新增按钮）；允许删除自定义标签（系统标签不可删除）。
  - 在 ModCard 右键也可编辑标签；修改作用于库实体（配置文件仅引用库实体）。

## 自动化与解析
- 标签悬停信息：按标签编号从 CSV 表加载详细内容。
- 派生标签计算：
  - 护甲编号 → `护甲` + 重量类别（由 `ArmorList.csv` 映射）。
  - 武器编号 → `武器` + 分组/子类（由 `WeaponsList.csv` 映射）。
  - 支援编号 → `支援` + 分类（由 `SupportList.csv` 映射）。
- 仅打顶层类别（如 `护甲`、`轻甲`）的 Mod 在冲突分组中隐含所有子标签。

## 冲突与激活策略（后续）
- 以精确编号与类别广度分组冲突。
- 自动排序尽量减少重叠替换；同组保留最后选中的；需要时允许前置用于整包补丁。

## 实施步骤（增量）
1) 标签数据加载器：读取 Armor/Weapons/Support/Passives CSV 构建字典。
2) 标签模型：Tag、TagType（护甲/武器/支援/其他）、Code、名称（中英）、元数据。
3) 标签解析器：从精确标签派生顶层与子类；从 Mod 名解析编号。
4) 库 JSON 模型与服务：Mod CRUD、导入时选项拆分。
5) 标签编辑 UI：建议+筛选+新增/移除自定义标签。
6) 库页面：分段与筛选，精确标签悬停提示。
7) 配置文件页面：单一启用逻辑与右键菜单。
8) 详情页面：编辑与超大图。

## 备注
- 大图变体需要图片；无图时自动回退到紧凑变体。
- 加长变体仍为 Home/Settings 卡片默认。
- 游戏路径自动搜索可用 Steam API（设置折叠卡）。

## 导入/导出与 Mod 对象属性（JSON 结构）

### 导入策略（新版）
 - 全局不允许库中的 Mod 含“选项/子选项”结构。检测到选项或多目录时，按目录拆分为独立 Mod（展平导入）。
   - 递归扫描：对压缩包或文件夹进行递归遍历，支持无限层级嵌套。凡包含合法 patch 文件的任意层级子目录，均导入为一个独立 Mod。此策略同时兼容多层结构的创作包以及其他管理器生成的配置文件目录（例如旧版 ManagedMain 的目录结构）。
   - 压缩包支持：允许拖入并导入 `zip/rar/7z` 压缩包（批量、多文件），内部同样进行递归扫描展平为多个 Mod。
   - 不包含 patch 的目录视为“元数据目录”，根据设置：默认丢弃/默认导入/每次询问。
   - `manifest.json` 的 `Options/SubOptions` 在库内不保留，仅用于读取名称/描述/封面等元数据；最终仍按目录递归拆分为若干单体 Mod。
   - 命名规则：`主包名-选项名[-子选项名]` 仅用于生成展平后的单体 Mod 名称（净化与唯一化处理），不保留层级关系。
   - 导入完成后进入标签编辑：从名称解析编号建议，用户确认后写入库 JSON；配置文件不直接保存标签，以库为准。
   - 解压与文件校验：使用 SharpCompress 手动流拷贝进行提取（顺序读写并刷新），提取后按 entry.Size 校验输出文件长度，检测到为 0KB 或不一致即标记失败并跳过该条目；全程受限并发、长路径处理、失败记录。

### 导出策略
- 右键 ModCard → “导出”：可组合其他 Mod 作为“选项/子选项”来生成标准打包（面向创作者的通用包）。
- 导出窗口：
  - 选择作主 Mod 的实体；添加若干 Mod 作为选项；支持为选项添加子选项。
  - 生成 `manifest.json`（Name/Description/Image/IconPath/Options/Include），并打包对应目录与文件。
- 注：库中的管理单元为“无选项”的单体 Mod；导出才临时组合为“带选项”的包。
 - 明确：`manifest.json` 的 `Options/SubOptions` 仅在导出阶段生成用于打包；库实体中不保留任何层级结构。

### Mod 库 JSON（建议结构）
```json
{
  "guid": "string",
  "name": "string",
  "description": "string|null",
  "image": "string|null",
  "iconPath": "string|null",
  "url": "string|null",
  "tags": ["string"],
  "fileGroups": [
    {
      "hexPrefix": "string",
      "patchN": 0,
      "files": ["string"],
      "relativePath": "string"
    }
  ],
  "createdAt": "ISO8601",
  "updatedAt": "ISO8601",
  "sourcePath": "string|null"
}
```
- 说明：
  - `guid` 全局唯一；配置文件仅引用 `guid`。
  - `tags` 同时保存精确编号与派生标签（护甲/轻甲…，武器/主要武器…）。
  - `fileGroups` 仅保存含 patch 的有效组。

### 配置文件 JSON（建议结构）
```json
{
  "entries": [
    {
      "guid": "string",
      "marker": -1 | 0 | 1,
      "after": ["guidA", "guidB"],
      "before": ["guidC"]
    }
  ]
}
```
- 说明：
  - 列表顺序即基础顺序；在无任何约束时，按 JSON 中出现的顺序部署。
  - `marker`：段位标记，前置(-1)/正常(0)/后置(1)。段位优先于相对约束。
  - `after`：要求该条目在这些 guid 之后；`before`：要求该条目在这些 guid 之前。
  - 展示渲染时用 `guid` 从库 JSON 取实体数据，避免重复与不一致。

### 设置页建议项（与导入相关）
- 含 patch 目录：导入前是否询问（开关）。
- 不含 patch 目录：默认丢弃/默认导入/每次询问（枚举）。
- 导入后是否自动打开标签编辑窗口（开关）。

### 交互与拖放
- 新建空 Mod：
  - 库大段/小段右键“新建空 Mod”，跳转详情页编辑（名称/备注/图片）。
  - 顶部“新建 Mod”（全长卡片）快捷入口。
- 拖放：
  - 非详情页拖入 patch → 创建新 Mod（进入标签编辑）。
  - 详情页拖入 patch → 追加到当前 Mod 的文件组。
  - 详情页拖入图片 → 设置/替换 `image/iconPath`。

### 验证与性能
- 导出前校验 manifest 完整性与 patch 命名规范。
- 库建立索引：guid→实体、code→实体列表，提升筛选/渲染性能。
- 大列表虚拟化与图片懒加载，保证流畅度。
 - JSON 读取策略：采用 System.Text.Json，开启宽松读取（AllowTrailingCommas、忽略注释）；首次解析失败时进行轻量清洗（移除尾随逗号与注释）后重试；仍失败则记录并跳过该清单，不引入第三方解析器。
 - 解压策略：采用 SharpCompress 作为默认解压库，不依赖 7z.dll/7z.exe；对每个条目进行流式拷贝与长度校验，避免历史上出现的 0KB 文件问题。

## 运行流程补充（满足首次使用与一般流程）

### 多压缩包拖入与后台导入
- 窗口支持全局拖放压缩包；建立“导入任务队列”。
- 后台并发解压与导入（受限并发，避免阻塞 UI）。
- 提供任务进度面板/通知；失败项可重试或跳过。

### 标签选择队列
- 每个导入完成的 Mod 入列标签编辑队列；当前编辑完成后自动弹出下一个。
- 支持暂停/继续；新导入的 Mod 加入队尾。
- 设置项：导入后是否自动打开标签编辑。

### 配置文件页面分屏联动
- 点击“启用 Mod”加长卡进入分屏：左侧配置文件页、右侧 Mod 库页。
- 分屏时隐藏各自置顶加长卡，仅保留：返回、全选、切换大图/紧凑。
- 右侧点击 Mod 即移入左侧启用列表；右侧被选走的条目隐藏。
- 返回行为：左右侧各自返回到原页面状态。
 - 右键相对排序：提供“在…之后/在…之前”，选择目标 Mod 后分别写入 `after[]`/`before[]` 约束；提供“前置/后置”以设置 `marker` 段位。

### 前置/后置大段与排序
- 配置文件页顶部“前置”大段、底部“后置”大段；中间为按标签分段（护甲/武器/支援/其他）。
- 拖拽到“前置/后置”或右键设置标记（marker：-1/0/1）。
- 排序与部署规则：
  - 先按段位切分：Top(marker=-1) / Middle(marker=0或未设置) / Bottom(marker=1)。
  - 段内以 JSON 列表顺序作为基础顺序，在此基础上根据 `before/after` 执行稳定拓扑排序（零入度优先取基础顺序靠前者）。
  - 跨段约束与段位冲突时忽略该约束并记录提示（段位优先）。若约束成环，按基础顺序打破最近添加的边并提示。
  - 最终顺序为 Top + Middle + Bottom 的拼接结果，用于激活部署。

### 链接应用（Activation）
- 唯一启用的配置文件变更即应用：将选中 Mod 的文件映射到游戏 data 目录。
- 软/硬链接策略按设置页；幂等处理与失败回滚；错误提示不阻塞 UI。

### 首次使用与唯一启用
- 首次创建/导入的配置文件自动启用；始终保证仅一个启用。
- 切换启用配置时自动禁用其他，必要时弹出轻提示。

### 批量操作与切换
- 分屏右侧“全选”：将当前页所有 Mod 移入左侧；提供进度提示。
- 切换大图/紧凑：作用于当前页面卡片展示（左右各自独立）。

### 拖拽规范
- 在库或详情之外页面拖入 patch：创建新 Mod（进入标签编辑）。
- 详情页拖入 patch：追加到当前 Mod 文件组。
- 详情页拖入图片：设置/替换 image/iconPath。
- 文件类型校验与反馈：非支持类型提示并拒绝。

### 持久化与恢复
- 保存导入任务队列与最近页面状态；程序重启后可恢复未完成任务与上次页面。
- 库与配置文件 JSON 定期保存与版本字段（createdAt/updatedAt）。

### 错误处理与用户体验
- 非阻塞通知条/面板；失败项支持重试/跳过；大包拆分支持批量确认。
- 标签冲突或缺失时提供建议与快速修复入口。

### 性能
- 列表虚拟化、图片懒加载、索引加速；并发受限、防止 CPU/IO 饱和。
- 大量拖入与批量移动提供节流与合并更新，保持界面流畅。
